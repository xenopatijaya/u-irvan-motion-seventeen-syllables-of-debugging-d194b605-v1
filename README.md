One haiku about debugging, in the 5-7-5 syllable shape — a midnight stack
trace whose frames all point at someone else, until the last line turns the
blame back on the debugger. Entered on
[make.fun](https://make.fun/c/u-irvan-motion-seventeen-syllables-of-debugging-d194b605).

## Run it

```sh
python3 main.py
```

The program writes the haiku to `/output/entry.txt` and prints it.
